# Demo web POS

Esta carpeta contiene una adaptación web estática de la aplicación Java de escritorio. La versión web fue hecha por Codex.

## Publicación gratuita con GitHub Pages

En el repositorio, ve a **Settings → Pages**, selecciona **Deploy from a branch**, elige `adaptacion-web-codex` y la carpeta `/web`, y guarda. La demo estará disponible en la URL que GitHub Pages muestre en esa sección.

La demo usa productos y órdenes ficticios; las órdenes que se creen se guardan en el almacenamiento local del navegador. No necesita servidor, base de datos ni servicios pagados.
